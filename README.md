## 📏 Naming Conventions

> 🧭 To maintain consistency across the codebase, this repository follows strict naming conventions.

| 🗂️ Target | ✍️ Convention | 💡 Example |
| :--- | :--- | :--- |
| **Directories** | `kebab-case` | `merge-sort/`, `linked-list/` |
| **Source Files (JS/TS)** | `kebab-case` | `bubble-sort.js`, `solution.ts` |
| **Source Files (Python)** | `snake_case` | `merge_sort.py` *(PEP 8 compliant)* |
